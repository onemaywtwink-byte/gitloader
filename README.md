# GitLoader 2.0

Десктопное приложение для загрузки локальных проектов на GitHub.

![Electron](https://img.shields.io/badge/Electron-28-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## Возможности

- **Загрузка проекта** — создаёт новый репозиторий или отправляет изменения в существующий
- **Перетаскивание папки** прямо в окно, анализ проекта: число файлов, размер, тип проекта, ветка, незакоммиченные изменения, крупные файлы
- **Проверка названия репозитория на лету**: новый он или уже существует, как будет называться после транслитерации
- **Организации** — можно загружать не только в свой аккаунт, но и в организации
- **Описание, ветка, сообщение коммита, публичный/приватный**
- **Шаблоны .gitignore** с GitHub (с автоопределением типа проекта), **лицензия** (MIT, Apache 2.0, GPL v3…), автоматический **README.md**
- **Защита от типичных ошибок**: `node_modules` и `.env` исключаются, файлы больше 100 МБ убираются из коммита, при расхождении с GitHub выполняется синхронизация (pull --rebase), повтор при сетевых сбоях, опциональный force push
- **Пошаговый прогресс и журнал git-команд**, кнопка отмены
- **Мои репозитории** — список с поиском, фильтрами и сортировкой; клонирование на компьютер, копирование ссылки, загрузка в выбранный репозиторий
- **Релизы** — публикация новых версий программы: тег (с подсказкой следующей версии), описание изменений (можно дополнить автосписком от GitHub), файлы для скачивания с прогрессом загрузки, пре-релизы и черновики. Для существующих релизов: дозагрузка и замена файлов, публикация черновика, удаление. Постоянная ссылка вида `.../releases/latest/download/файл.exe` всегда ведёт на самую свежую версию — её удобно использовать для обновлений
- **История загрузок** — повторная загрузка в один клик
- **Настройки** — светлая/тёмная/системная тема, видимость и ветка по умолчанию, автор коммитов (аккаунт GitHub, git config или вручную)

## Безопасность

- Токен хранится зашифрованным средствами ОС (Electron `safeStorage`)
- Токен **не записывается** в `.git/config` проекта — он передаётся git только на время команды. Если старая версия GitLoader оставила токен в адресе remote, он будет удалён при следующей загрузке
- Все запросы к GitHub API идут по HTTPS с проверкой сертификата; токен маскируется в журналах

## Требования

- [Node.js](https://nodejs.org) 18+
- [Git](https://git-scm.com/downloads)

## Запуск

Двойной клик по `запуск.bat` (сам установит зависимости), либо:

```bash
npm install
npm start
```

## Как получить токен

1. Нажмите в приложении «Создать токен на GitHub» — откроется страница с уже отмеченными правами `repo` и `read:org`
2. Укажите срок действия и нажмите **Generate token**
3. Скопируйте токен и вставьте его в приложение

Подойдёт и fine-grained токен с правами **Administration: Read and write** (для создания репозиториев) и **Contents: Read and write**.

## Сборка .exe

```bash
npm run build
```

Портативный исполняемый файл появится в папке `dist`.

## Горячие клавиши

- `Ctrl + O` — выбрать папку
- `Ctrl + Enter` — загрузить
